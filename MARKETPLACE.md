**Tagline:** Provision SolusIO (SolusVM 2) services from PeltyCMS orders

## SolusIO (SolusVM 2) provisioning for PeltyCMS

Create, suspend, unsuspend and terminate customer services on SolusIO (SolusVM 2) when orders are paid or cancelled. Credentials stay in Pelty secrets; the module runs as sandboxed WASM.

### Features
- Create / suspend / unsuspend / terminate
- Password + package sync hooks
- Works with Pelty product module mapping
- MythicCloud panel download supported

### Requirements
- Reachable SolusIO (SolusVM 2) API/panel
- API token or login configured in Pelty
